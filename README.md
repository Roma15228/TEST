# Шаблон Мультиагентного Проекта (Agent Team Template)

Этот репозиторий/папка служит шаблоном для создания новых проектов с готовой мультиагентной структурой в Antigravity.

## Структура шаблона

```text
├── AGENTS.md               # Главный свод правил: роли (Тимлид, PO/Консультант, Разработчики, QA), workflow и DoD
├── PROJECT_STATUS.md       # "Память" проекта: задачи, архитектура, прогресс между сессиями и перезапусками
├── README.md               # Описание проекта
└── .agents/
    └── skills/             # Скиллы для агентов
        ├── product-owner/  # Инструкции для Владельца Продукта (консультации, бэклог, параллельная сессия)
        ├── project-lead/   # Инструкции для Тимлида по управлению задачами
        ├── qa-tester/      # Инструкции для Тестировщика по автотестам
        └── session-sync/   # Инструкции по сохранению и восстановлению контекста
```

## Как развернуть новый проект из этого шаблона
1. Самая простая единая команда:
   ```bash
   team my-cool-app
   ```
   Либо перейдите в любую папку и напишите:
   ```bash
   team
   ```
2. Команда `team` (или `lead`):
   - Если папка новая: сама скопирует шаблон, инициализирует Git и откроет диалог с **Team Lead**.
   - Если проект уже существует: автоматически восстановит историю сессий (`agy -c`) и продолжит работу с того места, где вы остановились!
