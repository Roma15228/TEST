## 🏗️ 4. Ключевые архитектурные решения (ADR)
- *Решение 1*: Архитектура монолита с разделением на API (`/api/tasks`, `/api/stats`, `/api/health`) и статический SPA-фронтенд (`/app/static/`).
- *Решение 2*: Хранение данных в модуле `storage.py` с потокобезопасным файловым сохранением в JSON (`data/tasks.json`).
- *Решение 3*: Автотесты с использованием `TestClient` с изоляцией данных через фикстуры временных файлов.
- *Решение 4*: Успешно скоординирована работа всей команды агентов (Product Owner, Team Lead, Backend, Frontend, QA).
